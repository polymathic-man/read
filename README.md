# Read

Daily literary passages for read-aloud practice — one excerpt, listen and read.

**Live site:** https://polymathic-man.github.io/read/

## What this is

Each update is a single passage with:

- Clean, focused reading layout
- Inline narration (press play to hear the passage)
- Source citation (book and line)

Built for voice practice: read aloud, work on delivery, rhythm, and presence.
